# Scope: querying rendered features, source features, and terrain height.

This guide shows how to find the features the map draws, or the features a
source has loaded, and how to read the height of the terrain.

Queries run through the map's render session. A rendered query reads the last
frame, so after a camera or style change, render a frame before you query.

## Query rendered features

To find what's drawn at a screen point or in a box, use
[](api:mln_render_session_query_rendered_features). Name the layers to query, or
leave them out to query every layer.

<Snippet page="query" region="rendered" />

## Query source features

To search a source's data instead of what's drawn, query the source by its ID
with [](api:mln_render_session_query_source_features), and for a vector source,
name the source layers. To keep only some features, pass a
[filter](https://maplibre.org/maplibre-style-spec/expressions/).

A source query only sees the tiles that the source has loaded for the current
view, and a source loads tiles only while a visible layer uses it.

<Snippet page="query" region="source" />

## Query the terrain's height

To read the height of the terrain at a coordinate, use
[](api:mln_render_session_query_terrain_elevation). The height is in meters
above sea level as the last frame drew it, so it includes the terrain's
exaggeration.

The query has no value where the style has no terrain, or where the session
hasn't loaded the ground yet. Before the session's first frame it fails instead,
since there is no frame to read.
