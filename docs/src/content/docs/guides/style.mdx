A style describes what a map shows: its sources supply data, and its layers draw
that data in order. This guide shows how to load a style and change its sources,
layers, images, terrain, and sky. Sources and layers use the JSON of the
[MapLibre style spec](https://maplibre.org/maplibre-style-spec/).

## Load a style

Set the style by URL with [](api:mln_map_set_style_url), or by JSON with
[](api:mln_map_set_style_json). Either one completes once the map has parsed the
style, or fails when the style doesn't load.

<Aside type="caution">
  Loading a style replaces the sources, layers, and images you added. Until the
  load completes, adding or changing them fails, so wait for it. A new map has
  no style, so load one first, even an empty one.
</Aside>

<Snippet page="style" region="load" />

## Add a source and a layer

Add a source by its ID and its JSON with [](api:mln_map_add_style_source_json).
The JSON is the same object that a style puts under `sources`. See
[Sources](https://maplibre.org/maplibre-style-spec/sources/) in the style spec.

Add a layer by its JSON with [](api:mln_map_add_style_layer_json). It draws on
top, unless you give the ID of a layer to draw it under. See
[Layers](https://maplibre.org/maplibre-style-spec/layers/) in the style spec.

<Snippet page="style" region="add" />

For GeoJSON data in memory, add a GeoJSON source with
[](api:mln_map_add_geo_json_source), then set its data with
[](api:mln_map_set_geo_json_source_data). The library processes the data in the
background, so a large document doesn't hold up your thread or the map. Set new
data the same way to update the source. When updates come faster than the source
can take them, it skips to the newest.

<Snippet page="style" region="geojson" />

To remove a source, first remove the layers that use it with
[](api:mln_map_remove_style_layer), then the source with
[](api:mln_map_remove_style_source).

## Change a layer

Set a layer property by its style-spec name and a JSON value with
[](api:mln_map_set_style_layer_property). This also covers `visibility` and
`filter`. A value can be an
[expression](https://maplibre.org/maplibre-style-spec/expressions/).

Each change can show up in its own frame. To show several changes together, send
them between [](api:mln_map_begin_command_group) and
[](api:mln_map_end_command_group).

<Snippet page="style" region="set-property" />

## Add an image

Add an image to the style by its ID and premultiplied RGBA pixels with
[](api:mln_map_set_style_image). Symbol layers then draw it by that ID in
`icon-image`.

<Snippet page="style" region="image" />

When a layer asks for an image the style doesn't have, the map sends a
missing-image event, whose [](api:mln_runtime_event_style_image.image_id) names
the image. Set the image when the event arrives.

<Snippet page="style" region="missing-image" />

## Show terrain

A style's [terrain](https://maplibre.org/maplibre-style-spec/terrain/) raises
the map onto the heights of a `raster-dem` source. Give the style a `terrain`
object, or set one with [](api:mln_map_set_style_terrain_json). JSON `null`
removes it, and [](api:mln_map_get_style_terrain_json) reads it back. The
terrain can name a source that the style doesn't have yet, and shows once you
add the source.

An `exaggeration` must be a finite number of at least 0. Setting one outside
that range fails, and a style document with one loads without its terrain.

<Aside type="caution">
  A pitched view of terrain needs the camera's center to follow the ground,
  which is off by default. Without it, the camera can sit under the ground and
  the map shows nothing. See [Follow the
  terrain](/maplibre-native-ffi/guides/camera/#follow-the-terrain).
</Aside>

## Show a sky

A style's [sky](https://maplibre.org/maplibre-style-spec/sky/) colors the sky
and horizon behind pitched terrain, and the fog that fades distant terrain. Give
the style a `sky` object, or set one with [](api:mln_map_set_style_sky_json).
JSON `null` removes it, and [](api:mln_map_get_style_sky_json) reads it back. A
member whose value doesn't convert keeps its default and logs a warning, as in a
style document, while the other members still apply.
